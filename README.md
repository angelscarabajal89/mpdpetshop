# Mi Perro Dinamita Pet Shop & Forrajería

Sitio web del catálogo y pedidos por WhatsApp.

## Administración privada
- Entrá a `/admin/` desde el sitio publicado.
- Iniciá sesión con GitHub usando un token personal de acceso limitado a este repositorio.
- Los productos se guardan en `productos.json`; las imágenes nuevas se guardan en `assets/uploads/`.
